# Examples

Rendered from `examples/styles/codebase-explainer.tsvg` (a made-up system: web app → API → Postgres + Redis) and from
the recipes in `../references/scenes.md`. Open them with the Read tool before designing scenes.

| File | What it shows |
|---|---|
| `example-session-cache-landscape.jpg` | the example video, one tile per beat (middle moment + its caption), Oizom paper theme |
| `example-session-cache-editor-dark.jpg` | four moments of the same video in `--theme oizom-dark` (black logos inverted with `dark="1"`) |
| `example-session-cache-portrait.jpg` | the same wide-stage document played in 9:16: it scales, nothing is re-laid out |
| `scene-recipes-landscape.jpg` | all 9 recipes: flow + packet, code proof, rows written, real UI with a ring, before → after, scale, drawn device, machines, the ending |

They show the quality bar and the house rules (one blue at a time, real logos, code you can read at 720p, a plain ending).
They are **not templates**: design every scene from the sentence it illustrates, and draw new pictures whenever the
recipes don't fit. For a wider range of drawn scenes see `../../tech-explainer/assets/`.
